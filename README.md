# Fix&Spacebook — Frontend Demo

Publiczne demo frontendu platformy lokalnych usług Fix&Spacebook.

## Uruchomienie

```bash
python3 -m http.server 8082
```

Otwórz w przeglądarce: http://127.0.0.1:8082

## Status

To demonstracyjny frontend. Dane z formularzy nie są zapisywane ani wysyłane na serwer.

## Bezpieczeństwo

Nie dodawaj haseł, tokenów, kluczy API, danych użytkowników ani plików .env.
